\subsection{$T_{\mathrm{grok}}$ Definition}

$T_{\mathrm{grok}}$ is defined as the first epoch where test accuracy $\geq 0.95$, with a stability window of 5 consecutive evaluations above 0.90. ``Epoch'' means a full pass through the training set (one optimizer step per minibatch, full dataset per epoch). This is consistent across all runs.

\subsection{SCRAMBLED Isomorphism Audit}

The SCRAMBLED representation applies a single fixed permutation $\pi: G \to G$ to all four CRT positions. The audit verifies:

\begin{itemize}
\item Same permutation applied to all positions: \textbf{Yes}
\item Equality preserved: \textbf{Yes}
\item Weight tying: \textbf{No} (untied input/output)
\item Conjugate at initialization: \textbf{Yes}
\item Max logit difference: \textbf{0.00}
\item Conclusion: SCRAMBLED is exactly conjugate to CRT at initialization via input embedding permutation. The two models are not meaningfully different from the model's perspective at init. SCRAMBLED does NOT test destruction of algebraic structure.
\end{itemize}

\section{Methodological Audits}
% ====================================================================

\subsection{Data Split Audit}

\begin{itemize}
\item Split: 30\% train / 70\% test, seed 42
\item Split at the level of underlying triples $(g, g^x, x)$, before representation encoding
\item All 48 generators ($\varphi(112) = 48$) represented in both splits
\item No encoded collisions across representations
\item Train/test coverage: all group elements appear in both splits
\end{itemize}

\subsection{Token Embedding Audit}

\begin{itemize}
\item Token namespace: shared between input and output (117 tokens)
\item Embedding: learned categorical (no numeric encoding of token values)
\item Input/output tying: \textbf{untied} (separate embedding and unembedding matrices)
\item Zero element: not in the vocabulary (group is $\mathbb{F}_p^*$, excludes 0)
\item Positional embeddings: learned, separate from token embeddings
\end{itemize}

\subsection{Fourier Implementation Audit}

\begin{itemize}
\item Generator dimension: all 48 generators included in the Fourier analysis
\item Centering: mean-center activations before computing the DFT
\item Aggregation: energy aggregated across generators and hidden dimensions
\item Nonconstant energy: DC component excluded from reported energy
\item 2D DFT: computed per hidden dimension over CRT coordinates $(r_7, r_{16})$
\end{itemize}

\subsection{Grokking Metric Audit}

\begin{itemize}
\item $T_{\mathrm{grok}}$: first epoch where test accuracy $\geq 0.95$
\item Stability window: 5 consecutive evaluations above 0.90
\item ``Epoch'': one full pass through the training set
\item Evaluation: every 100 epochs
\item Failed runs: censored at their final epoch
\end{itemize}

\subsection{Probe Audit}

\begin{itemize}
\item Probes: linear, trained on hidden states at the EOS position
\item Split independence: probes trained on train split, evaluated on test split
\item Targets: $x \bmod 7$ and $x \bmod 16$
\item Non-monotonic behavior: probe accuracy can fluctuate during training
\item Caveat: probe accuracy does not imply causal use
\end{itemize}

\subsection{Equivariance Audit}

\begin{itemize}
\item $\Aeq$: measures whether $\phi(cy) = \phi(y) \oplus \Delta$ for some shift $\Delta$
\item Generator-aware: computed per generator, then averaged
\item Test-test transformations: equivariance evaluated on held-out test data
\item Finding: $\Aeq$ rises concurrently with test accuracy, not before
\end{itemize}

\subsection{Ablation Audit}

\begin{itemize}
\item Previous full-rank ablation had a rank-mismatch problem ($AB$ subspace much larger than $A$ or $B$)
\item Top-$k$ ablation resolves this by comparing equal-rank subspaces
\item 100 rank-matched random controls per condition
\item 100 variance-matched random controls per condition
\item Separate construction/evaluation data (50/50 split)
\item All structured ablations at 0th percentile of random controls
\end{itemize}
